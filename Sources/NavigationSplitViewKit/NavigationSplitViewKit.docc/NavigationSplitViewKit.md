# ``NavigationSplitViewKit``

Build responsive three-column layouts with synchronized state for iOS, iPadOS, and macOS.

## Overview

NavigationSplitViewKit demonstrates a multi-column interface using SwiftUI's `NavigationSplitView`. It keeps valid selections through compact and expanded layouts, configures column visibility, and presents an optional inspector across Apple platforms.
